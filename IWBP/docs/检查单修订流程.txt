气象服务席检查单 · 修订流程（与业务提醒模块同步）
================================================

一、改哪里
  源文件：docs\气象服务席检查单工作项.xlsx
  三个班次区块（与导出脚本一致，勿随意改列结构）：
    · A1–C17  白班 08:30–18:00
    · A22–C32 夜班 17:30–次日 03:30
    · A37–C46 晨班 03:00–09:00
  每行：序号（数字）| 工作任务（文字）| 完成时间（Excel 时间型，导出为 HH:mm）

二、改完后怎么进工作台
  1. 保存 xlsx。
  2. 在项目根目录执行：
       python scripts\export_checklist.py
     会生成：
       docs\checklist-data.json（可读、可归档）
       docs\checklist-embed.min.json
     并自动替换 index.html 里 <script id="checklist-embedded-data"> 内嵌的检查单 JSON。
  3. 浏览器对 index.html 强刷（Ctrl+F5）或重新打开页签，否则可能仍用旧缓存页面。

三、版本号
  每次成功导出，checklist-data.json 里的 version 会在旧值基础上 +1，并写入 exportedAt 时间，便于以后对接服务端或排查「哪版表」。

四、质检存档（业务提醒卡片上点「质检存档」打开大窗口）
  · 仅自动保留「列表日期」在最近 31 天内的记录，更早的会从本机删掉。
  · 可按「日期 + 班次」筛选查看；换账号后筛选会重置为当天、全部班次。

五、值班员本地已完成记录
  完成状态存在浏览器 localStorage（按账号）。若你删行、改序号或合并条目，旧 key 可能残留为「幽灵」项；大改版时可让值班员清站点数据或换账号测试，生产上以后由服务端统一口径更佳。

六、首次从未嵌入过 index 的旧仓库
  若 index.html 里还没有 checklist-embedded-data，先执行一次：
       python scripts\patch_checklist_index.py
