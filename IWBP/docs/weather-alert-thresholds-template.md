# 气象告警阈值配置表（空表模板）

> **用途**：METAR（实况）与 TAF（预报）各一套表，**阈值列留空**由签派/运规填写正式数字。  
> **单位约定**：风 — m/s；主导能见度 — m；与运行规范一致。  
> **配套文件**：`data/weather-alert-thresholds-template.csv`（汇总）、`data/weather-alert-thresholds-template.xlsx`（多 Sheet）。

## 三、共用说明（填表前确认）

| 项 | 说明 |
|----|------|
| 国内 / 国际 | 可用不同 profile 各填一套，或在「适用范围」中注明 |
| METAR | 对当前观测生效 |
| TAF | 须先约定：取整份预报「最差条件」或是否单独评估 TEMPO/PROB 段 |
| 现象码 | 以公司解析字典与运规为准（TS、FG、FZ 族等） |

## 四、文件说明

| 文件 | 说明 |
|------|------|
| `data/weather-alert-thresholds-template.csv` | 全部表汇总为一个 CSV，便于版本对比与导入 |
| `data/weather-alert-thresholds-template.xlsx` | 与上表结构对应的多个工作表，便于打印与评审 |
| `npm run gen:threshold-xlsx` | 根据 `tools/gen-weather-alert-threshold-xlsx.cjs` 重新生成上述 xlsx（表结构变更时执行） |
