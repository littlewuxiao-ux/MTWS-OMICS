## 一、项目背景

气象团队积累了大量恶劣天气复盘材料（台风、雷雨、低能见度等），以 Word / PPT / PDF / TXT 散落硬盘，难以快速检索。  
原方案由曹骏编制（2026-05-31），目标：建设**复盘知识库 + 智能搜索引擎**，全离线、内网运行。

经评估后，在 `weather agent V2` 下新建独立子项目 `review-search/`，与 `index.html` **松耦合**；2026-06-10 已在分析屏增加入口与今日相关推荐。

## 二、已完成内容

### 2.1 核心功能

| 功能 | 状态 | 说明 |
|------|------|------|
| 文档解析 | ✅ | Word / PDF / PPT / TXT |
| 元数据提取 | ✅ | 机场、天气类型、日期、运行影响（规则引擎） |
| 语义向量 | ✅ | BGE-M3，本地 `models/bge-m3/` |
| 关键词检索 | ✅ | BM25 + jieba 分词 |
| 混合搜索 | ✅ | RRF 融合，支持三种模式切换 |
| 多维筛选 | ✅ | 机场 / 天气 / 影响 / 时间范围 |
| 原文追溯 | ✅ | 本机「打开原文」+ 远程「下载原文」 |
| Streamlit 界面 | ✅ | 智能搜索 / 文档入库 / 库管理 / 展示说明 |

### 2.2 技术架构

```
复盘文档 → 解析 → 分块 → BGE-M3 向量化 → Chroma 持久化
                              ↓
用户查询 → 语义检索 + BM25 → RRF 融合 → 筛选 → 结果展示
```

- **后端**：Python 3.10+
- **向量库**：ChromaDB（`data/chroma/`）
- **元数据索引**：`data/index_meta.json`
- **界面**：Streamlit（`app/main.py`）
- **样式**：`app/ui_styles.py`

## 三、日常使用

### 3.1 启动（上班开一次，最小化别关）

```powershell
cd "d:\weather agent\V2\review-search"
双击 start.bat
```

浏览器：`http://localhost:8501`  
推荐 API：`http://localhost:8502/api/recommend`（工作台分析屏自动调用）  
局域网：`http://本机IP:8501`（侧边栏显示）

`start.bat` 会同时启动 Streamlit（8501）与推荐 API（8502，最小化窗口）。

### 3.2 新增复盘

1. 文件放入 `data/documents/`
2. 界面 →「文档入库」→「扫描并入库新文档」

### 3.3 搜索模式

| 模式 | 适用场景 |
|------|----------|
| 混合搜索（推荐） | 日常值班检索 |
| 仅语义 | 口语化、自然语言提问 |
| 仅关键词 | 四字码、专有名词精确查找 |

相关度显示为**本次结果内相对百分比**（最高 = 100%），非答对概率。

### 3.4 首次部署（新电脑）

```powershell
pip install -r requirements.txt
python tools/download_model.py    # 下载 BGE-M3（一次性）
python tools/setup_semantic.py    # 可选：入库+重建向量
```

## 四、界面与体验优化记录

开发过程中逐项修复的问题：

| 问题 | 处理 |
|------|------|
| 语义模型未加载 | ModelScope 下载 BGE-M3；服务常驻内存 |
| Deploy 按钮干扰 | Streamlit 配置隐藏 |
| 仅显示语义搜索 | 增加混合 / 语义 / 关键词三模式 |
| 匹配度 0.03 难懂 | 改为相关度百分比 + 语义/关键词排名 |
| 顶栏圆角/灰边/文字不居中 | 多轮调整，最终 iframe + 占位块方案 |
| 侧栏文字看不清 | 恢复深色侧栏主题 |
| 侧栏菜单宽窄不一 | 统一 100% 宽度 |
| 局域网地址未对齐 | 合并为同一 HTML 区块 |
| 主区域无法滚动 | 移除错误的 overflow 覆盖 |
| 搜索框/高级筛选黑底白字看不见 | 主区域表单控件强制白底深字 |
